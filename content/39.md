# 本地模型

Rig 可以完全运行在你自己的硬件上。本地部署有两种方式：

- **本地服务器**：Rig 通过 HTTP 与之通信，例如 [Ollama](#ollama) 或 [llama.cpp](#llamacpp)。两者都内置于 `rig`，无需额外 feature。
- **进程内推理**：完全不需要服务器，例如用于补全的 [Candle](#candle) 和用于嵌入的 [fastembed](#local-embeddings-with-fastembed)。两者均为配套 crate，通过 `rig` 上的 feature 启用。

无论选哪种，它们的模型都像托管模型一样，可以接入 `AgentBuilder`、`EmbeddingsBuilder` 和向量存储。

## Ollama

`Ollama::new()` 访问 `http://localhost:11434` 上的守护进程，不使用身份验证。对于远程或受保护的守护进程，`Ollama::from_env()` 读取可选的 `OLLAMA_API_BASE_URL` 和 `OLLAMA_API_KEY`。

Ollama 提供两套聊天 API，Rig 分别提供对应模型：

- `client.completion(id)` 使用 Ollama 的 OpenAI 兼容端点 `/v1/chat/completions`。
- `client.native_completion(id)` 使用 Ollama 原生端点 `/api/chat`。只有此路由会发送 `num_ctx` 等模型参数，并将 `reasoning` 选项映射为 Ollama 的 `think`。

## Candle

`rig::candle`（`candle` feature）通过 [Candle](https://github.com/huggingface/candle) 在进程内使用 CPU 运行模型。你自行加载模型文件，把字节交给 Rig；该 crate 不访问文件系统或网络。

@@CODE_005@@

@@CODE_006@@

只有经过验证的检查点可以加载；其他检查点会被拒绝，而不是尝试猜测格式：

- **Llama 3 instruct**：单个未分片的 safetensors 检查点。
- **SmolLM2-360M-Instruct**：Q4\_K\_M GGUF。体积足够小，可以通过 WASM 在浏览器中运行。
- **Qwen3-4B**：官方 Q4\_K\_M GGUF，支持原生工具调用。仅支持原生目标平台。

GGUF 文件使用 `CandleModel::from_gguf(data)?`。GGUF 模型目前的上下文长度为 4096 token。Candle 的本地指标（提示词和生成 token 数、预填充时间、首 token 延迟、每秒 token 数）是类型化回复扩展，通过 `response.extras::<rig::candle::extension::CandleExt>()` 读取。

`rig::candle::pose` 提供 YOLOv8 姿态估计（`CandlePoseModel`），以流式方式输出图像序列每一帧中检测到的姿态。

Rig 仓库提供三个可运行示例：[`candle_local`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/candle_local) 从本地 GGUF 模型流式获取补全并打印 Candle 指标；[`candle_pose`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/candle_pose) 估计图像中的姿态；[`candle_wasm_chat`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/candle_wasm_chat) 在浏览器 Web Worker 内运行 SmolLM2 和 Rig Agent，聊天消息始终留在页面内。

## 使用 fastembed 生成本地嵌入

`rig::fastembed`（`fastembed` feature）在进程内运行 [fastembed](https://github.com/Anush008/fastembed-rs) 嵌入模型。`fastembed` feature 会在首次使用时从 Hugging Face 下载模型，并下载 ONNX Runtime 二进制文件；`fastembed-hf-hub` 和 `fastembed-ort-download-binaries` 可以分别启用这两部分。它仅支持原生目标平台。

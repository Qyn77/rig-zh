# 媒体功能：图片、音频与转写

除了文本补全和嵌入，Rig 还能生成图片、将文本转换为语音，以及转写音频。这些功能都像补全模型一样，从服务商客户端获得相应模型，再用请求调用：

| 任务 | 客户端方法 | 请求构建器 | 响应字段 |
| --- | --- | --- | --- |
| 图片生成 | `client.image_generation(model)` | `ImageGenerationRequestBuilder` | `image: Vec<u8>` |
| 音频生成（文本转语音） | `client.audio_generation(model)` | `AudioGenerationRequestBuilder` | `audio: Vec<u8>` |
| 转写（语音转文本） | `client.transcription(model)` | `TranscriptionRequestBuilder` | `text: String` |

每个响应还包含 `usage`、服务商名称 `provider`、服务商报告的 `model`，以及 `raw` 原始响应，供你访问 Rig 未做标准化的内容。

开始之前

- 了解如何创建服务商客户端，见[服务商与客户端](/docs/concepts/provider_clients)。
- 图片与音频生成需要 Cargo feature：`rig = { version = "0.46.0", features = ["image", "audio"] }`。转写不需要额外 feature。
- 设置服务商 API Key，例如 `OPENAI_API_KEY`；示例通过 `from_env()` 读取。

## 服务商支持情况

| 服务商 | 图片生成 | 音频生成 | 转写 |
| --- | --- | --- | --- |
| OpenAI | 支持（`gpt-image-*`、DALL·E） | 支持（`tts-1`、`tts-1-hd`） | 支持（Whisper） |
| Gemini | 支持 | 不支持 | 支持 |
| 兼容 OpenAI 的服务商（Azure、Groq、Hugging Face、Mistral 等） | 取决于服务商是否提供 | 取决于服务商是否提供 | 取决于服务商是否提供 |

兼容 OpenAI 的服务商共用 OpenAI 客户端类型，因此会暴露相同方法；若服务商没有对应端点，调用会返回服务商错误。模型名称见[模型服务商页面](/docs/integrations/model_providers)。

@@ANCHOR:media-as-input@@

## 将媒体作为输入

如果要把图片、音频、视频或文档**发送给**模型，而不是生成它们，请用 `UserContent` 构造函数将其加入用户消息。见[向模型发送文件](/docs/concepts/loaders#sending-files-to-the-model)。

## 基础

围绕核心构件编写的最小实用程序。相关概念：[Agent](/docs/concepts/agent)、[补全](/docs/concepts/completion)、[结构化输出](/docs/concepts/extractors)。

| 示例 | 演示内容 |
| --- | --- |
| [`agent`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/agent) | 完整展示服务商 → 模型 → Agent → 提示词调用链。 |
| [`extractor`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/extractor) | 将类型化提取结果写入结构体，分别演示带用量元数据和不带元数据的方式。 |
| [`sentiment_classifier`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/sentiment_classifier) | 最小类型化提取器，将句子分类为枚举值。 |
| [`multi_extract`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/multi_extract) | 使用 `futures::try_join!`，对同一文本并行执行多次提取。 |
| [`agent_with_context`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/agent_with_context) | 为 Agent 附加静态上下文文档（Cohere）。 |
| [`agent_with_loaders`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/agent_with_loaders) | 用 `FileLoader` 将磁盘文件加载到 Agent 上下文中。 |
| [`frozen_api`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/frozen_api) | 八个短程序（`cargo run -p frozen_api --example p1_one_prompt` 等）：单次提示词、流式输出、类型擦除后的模型、工具、本地及 HTTP 操作、OpenAI 兼容服务商、自定义传输层。 |

| 示例 | 演示内容 |

| [`chain`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/chain) | 手动检索：查找上下文，将其合入提示词，再发出提示词。 |
| [`rag_ollama`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/rag_ollama) | 对本地 Ollama 模型执行相同的 RAG 流程。 |
| [`vector_search`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/vector_search) | 使用 OpenAI 嵌入的内存向量索引：对比 `top_n` 和 `top_n_ids`。 |
| [`vector_search_cohere`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/vector_search_cohere) | 分别使用 Cohere 文档嵌入和查询嵌入。 |
| [`vector_search_ollama`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/vector_search_ollama) | 使用本地 Ollama 嵌入模型进行向量搜索。 |
| [`rag_dynamic_tools`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/rag_dynamic_tools) | 每次发送提示词时，通过对工具描述做向量搜索来选择工具。 |
| [`rag_dynamic_tools_multi_turn`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/rag_dynamic_tools_multi_turn) | 跨多轮运行动态检索工具。 |
| [`pdf_agent`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/pdf_agent) | 加载并分块 PDF，用 Ollama 生成嵌入，再根据文档回答问题。 |
| [`gemini_extractor_with_rag`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/gemini_extractor_with_rag) | 在 Gemini 上为类型化提取器提供检索结果。 |
| [`custom_vector_store`](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/examples/custom_vector_store) | 为自己的后端实现 `VectorStoreIndex`。 |

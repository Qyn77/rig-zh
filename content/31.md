# 构建命令行聊天机器人

`rig::integrations::cli_chatbot` 将 Agent 转换为交互式终端 REPL。它从标准输入读取内容，保留对话历史以提供各轮上下文，将 Agent 回答流式输出到标准输出，并在输入 `exit` 时停止。无需自己编写输入循环，就能快速在本地试用 Agent。

## 使用自定义聊天类型

如果希望 REPL 背后使用 `Agent` 以外的类型，实现 `cli_chatbot::Chat` trait，再将值传给 `.chat(..)`，而不是 `.agent(..)`。该 trait 只有一个方法：针对调用方持有的历史运行一轮，追加本轮提交的消息，并返回回答文本。

@@CODE_003@@

自定义 `Chat` 会在轮次结束后一次性打印完整回答，只有 `Agent` 路径支持流式输出。

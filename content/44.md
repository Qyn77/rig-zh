# Neo4j

`rig::neo4j`（`neo4j` feature）在 Neo4j 原生向量索引上执行 Rig 向量搜索。如果嵌入保存在图节点上，并且你希望直接进行相似度搜索、不把向量搬到独立存储，可以使用它。

@@ANCHOR:prerequisites@@

## 前置条件

- **Neo4j GenAI 插件。** Neo4j Aura 默认启用；自行管理的实例需要安装。
- **覆盖待搜索节点的向量索引。** 使用 Cypher（`CREATE VECTOR INDEX ...`）或下文的 `Neo4jClient::create_vector_index` 创建。Neo4j 在后台构建新索引，因此索引可能无法立即查询。

## 工作原理

- **`Neo4jClient::connect(uri, user, password)`** 打开连接。`Neo4jClient::from_config(config)` 接收 `neo4rs::Config`，可设置数据库名、TLS、连接池大小等；`client.graph` 是底层 `neo4rs::Graph`，供你执行自己的 Cypher。
- **`create_vector_index(config, node_label, ndims)`** 在索引不存在时创建它，并尽力等待其上线。`IndexConfig::new(name)` 默认使用 `embedding` 属性和余弦相似度；通过 `.embedding_property(..)` 和 `.similarity_function(..)` 修改。`ndims` 必须与查询模型的向量维度相同：`model.capabilities().ndims`。
- **`get_index(model, index_name)`** 为现有索引返回 `Neo4jVectorIndex`。它从索引读取节点标签和嵌入属性；索引不存在时返回错误。
- **`insert_documents`** 在索引对应标签下为每个嵌入创建一个节点，将文档字段平铺为节点属性，向量放入嵌入属性，参与嵌入的文本放入 `embedded_text`。
- **`top_n::<T>(req)`** 查询索引中最近的 `samples` 个节点，把每个节点（去掉嵌入后）反序列化为 `T`。`result.id` 是 Neo4j 内部节点 ID。`top_n_ids` 仅返回 ID 和得分。

由于向量是普通节点属性，你可以在自己的 Cypher 中组合相似度搜索和图遍历。[`rig-neo4j` 示例](https://github.com/0xPlaygrounds/rig/tree/v0.46.0/crates/rig-neo4j/examples)包含一个电影推荐图，为已有节点添加嵌入后执行查询。

注意

不要在 Neo4j 请求中设置 `threshold`：Rig 将它与节点上的 `distance` 属性比较，而不是与搜索得分比较。这会过滤掉所有不带该属性的节点结果。请自行根据 `result.score` 过滤。

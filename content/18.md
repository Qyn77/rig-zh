# 加载器

加载器从磁盘文件或字节读取内容，转换成文本，供 Agent 用作上下文，或嵌入向量存储。它们负责 glob 匹配、目录遍历和单个文件的错误处理，避免一个损坏文件中断整批处理。Rig 提供以下加载器：

- 任意文本文件：`FileLoader`
- PDF：`PdfFileLoader`（需要 `pdf` feature）
- ePub 电子书：`EpubFileLoader`（需要 `epub` feature）

如果模型本身支持读取该文件格式，例如多数大型服务商支持 PDF 和图片，也可以跳过文本提取，直接[在消息中发送文件](#sending-files-to-the-model)。

开始之前

- [安装 Rig](/docs/installation)，需要相应加载器时启用 `pdf` 或 `epub` feature：`rig = { version = "0.46.0", features = ["pdf", "epub"] }`。
- 了解如何构建 [Agent](/docs/concepts/agent)；加载后的文件通常会成为 Agent 的上下文。

## 向模型发送文件

许多模型可以直接接收文档和图片。用 `UserContent` 的各部分构建用户消息，再把消息交给模型。不同来源有对应的构造函数：

- `UserContent::document_text(text, media_type)`：用于 Markdown、CSV 等文本格式；
- `document_base64`、`document_raw`（字节）和 `document_url`：用于 PDF 等二进制文档；
- 其他媒体使用对应的 `image_*`、`audio_*`、`video_*` 构造函数。

@@CODE_004@@

Rig 会按服务商要求编码各部分。不同服务商和模型支持的媒体类型不同，详见[模型服务商页面](/docs/integrations/model_providers)。

# 模型上下文协议

[模型上下文协议](https://modelcontextprotocol.io)（MCP）是一种向 LLM 应用公开工具的标准方式。MCP **服务器**承载工具；MCP **客户端**发现并调用工具。Rig Agent 通过官方 Rust MCP SDK [`rmcp`](https://docs.rs/rmcp) 充当客户端：每个 MCP 工具都会成为 Agent 可以调用的 Rig 工具。

## 超时、元数据与结果

- **超时。** 每次 MCP 调用默认有五分钟截止时间（`DEFAULT_MCP_TOOL_TIMEOUT`）。通过 `McpTool::with_timeout(..)` 修改单个工具，或通过 `McpClientHandler::with_timeout(..)` 修改处理器中的全部工具；传 `None` 表示不设截止时间。超时调用会像其他工具错误一样失败，Rig 会尝试在服务器上取消它。
- **请求元数据。** 如果要在调用时发送 MCP `_meta`，又不希望模型看到，将 `McpMeta(meta)` 放入调用的 `ToolContext`。
- **结果。** 模型看到的是工具内容。完整的 `CallToolResult`、其中的 `structuredContent` 和响应 `_meta` 会发布到工具上下文的结果中（`McpCallToolResult`），供钩子和代码读取。服务器标记为 `is_error` 的结果会成为失败的工具调用。
- **断开连接。** 每个 MCP 工具都带有与连接绑定的存活检查，因此工具注册表可以退役服务器已断开的工具。

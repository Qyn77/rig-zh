## 刚才发生了什么

- `OpenAI::from_env()` 使用 API Key 创建服务商客户端，通过 Rig 的共享 HTTP 客户端发送请求。
- `client.completion(openai::GPT_5_5)` 返回一个 `Model`，代表该服务商的一个模型。可以直接调用它，也可以交给 Agent。
- `AgentBuilder::new(model)` 开始构建 Agent；`.preamble(...)` 设置系统提示词；`.build()` 完成构建。
- `.prompt(...)` 运行 Agent 并返回 `PromptResponse`。`.output()` 是最终文本；响应还包含 token `usage` 和本次运行的 `messages`。

Agent 不止能做单轮问答：添加工具可让模型调用你的代码；接入知识库可实现检索增强生成（RAG）；使用 `.stream()` 可逐段接收输出；也可以保留对话历史。

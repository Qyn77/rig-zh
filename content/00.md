# 简介

Rig 是用于构建大模型应用和智能体（Agent）的 Rust 库。它为 20 多家模型服务商（OpenAI、Anthropic、Gemini、Cohere、Ollama 等）、向量存储和工具提供统一 API。你可以用几行代码搭起 Agent，再逐步扩展成生产系统，无需更换框架。

@@ANCHOR:why-rig@@

## 为什么选择 Rig

- **类型安全**：工具参数、结构化输出和生成选项使用普通 Rust 类型，编译器会检查接口和类型是否匹配。模型返回的数据仍需在运行时解析与校验。
- **跨服务商统一 API**：不同服务商使用相同的模型、Agent 和嵌入类型。切换后端时更换客户端即可，无需重写业务代码。
- **可移植的核心，可选的运行时**：服务商、工具和向量存储的接口约定位于小型核心库中，Agent 循环构建在其上。你既可以使用现成 Agent，也可以直接调用模型并编写自己的循环。
- **覆盖 Rust 可运行的环境**：可以发布原生二进制，也可以把核心和 Agent 运行时编译为 WebAssembly，在浏览器中使用。
- **沿用现有技术栈**：如果项目已经使用 Rust，就能用同一套工具链和类型系统构建 AI 功能。

## Rig 提供什么

- **跨服务商的补全与嵌入**：支持类型化的生成选项，例如推理强度、提示词缓存和服务等级。各服务商会明确映射这些选项，或拒绝不支持的选项。
- **Agent**：支持系统提示词、工具、动态上下文、对话记忆和生命周期钩子；运行状态可序列化，并能逐步执行、暂停和恢复。
- **检索增强生成（RAG）**：可使用内存向量存储，也可接入十余种向量数据库。
- **结构化提取**：从非结构化文本中提取具有类型的数据。
- **流式输出**：文本、推理内容和工具调用参数一到达就能处理。
- **生产工具**：提供类型化错误、token 用量与费用统计、兼容 OpenTelemetry 的追踪、调用记录与重放，以及用于离线[测试](/docs/concepts/testing)的模拟模型。

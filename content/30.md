# 构建航班搜索助手

本教程使用 [Rig](https://github.com/0xPlaygrounds/rig) 在 Rust 中构建航班搜索 Agent。它通过调用自定义[工具](/docs/concepts/tools)查询航班搜索 API，查找两个机场之间的航班。它展示了常见的 Agent 工具调用流程：定义 `Tool`，注册给 Agent，再由模型决定何时调用。

用户询问“帮我找下周五从 SAT 到 ATL 的航班”时，模型读取工具描述和参数 schema，返回携带 JSON 参数的工具调用；Rig 执行你的 `call` 方法，把结果发送回模型，模型再据此生成最终答案。

## 航班搜索工具

创建 `src/flight_search_tool.rs`。Rig 工具是实现 [`Tool`](/docs/concepts/tools) 的类型：

- `NAME`：模型调用工具时使用的名称。
- `Args`：由模型发送的 JSON 参数反序列化得到。
- `Output`：返回给模型的结果；任何实现 `Serialize` 的类型都可以，这里使用 `String`。
- `Error`：你自己的错误类型。`call` 失败时，运行仍会继续：Rig 将简短的失败通知作为工具结果发送给模型，错误详情留在你的应用侧用于日志和追踪，让模型可以重试或作出解释。
- `description` 和 `parameters`（`Args` 的 JSON Schema）：模型据此决定是否调用工具，以及如何调用。

@@CODE_002@@

响应解析使用普通 `serde_json::Value` 索引：字段缺失返回 `Value::Null`，不会 panic，因此 API 响应改变时只会退化为“Unknown”字段，而不会崩溃。返回紧凑、易读的列表可减小模型上下文，模型不需要原始 API 响应。

`FlightSearchTool` 是普通类型，因此可以不经过模型，直接对 `call` 做单元测试。

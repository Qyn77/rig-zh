# Core Concepts

Rig is built from a small set of composable pieces. Once you see how they layer,
everything else is a variation on the same pattern. This page is the map; each
piece has its own page.

@@ANCHOR:the-mental-model@@

## The mental model

The building blocks stack from the bottom up:

- **Provider clients** hold a vendor’s configuration (OpenAI, Anthropic, Gemini,
  Ollama, and more) and a transport.
- **Models** come from a client: completion models for text generation,
  embedding models for vectors, plus transcription, image, and audio models where
  the provider has them. You can call a model directly with a `CompletionRequest`.
- **Agents** wrap a completion model with a preamble, tools, and context, and run
  the tool-calling loop for you. Each prompt is an `AgentRunner` you can tune per
  run; hooks observe or steer the loop.
- **Tools, RAG, and memory** extend an agent: tools let it call your code, RAG
  pulls in relevant documents from a vector store, and memory loads and saves
  conversation history.
- **Workflows** compose all of the above into multi-step programs with plain Rust.

The [Quickstart](/docs/quickstart) builds the first three layers (provider client, model, agent)
as a complete program.

## Which piece do I need?

Start from the task, not the type.

| I want to… | Page |
| --- | --- |
| connect to a provider | [Providers & Clients](/docs/concepts/provider_clients) |
| send one request without the agent loop | [Completions](/docs/concepts/completion) |
| let the model call tools over several turns | [Agents](/docs/concepts/agent) |
| configure one agent run | [AgentRunner](/docs/concepts/agentrunner) |
| observe or steer the loop | [Hooks](/docs/concepts/hooks) |
| step, pause for approval, or resume a run | [Durable runs](/docs/concepts/runs) |
| let the model call my code | [Tools](/docs/concepts/tools) |
| get typed data out of text | [Structured Output](/docs/concepts/extractors) |
| stream tokens as they arrive | [Streaming](/docs/concepts/streaming) |
| hold a conversation | [Memory](/docs/concepts/memory) |
| embed text | [Embeddings](/docs/concepts/embeddings) |
| answer from my documents | [Vector Stores & RAG](/docs/concepts/rag) |
| load files (text, PDF, EPUB) | [Loaders](/docs/concepts/loaders) |
| generate images, audio, or transcripts | [Media](/docs/concepts/media_generation) |
| orchestrate known steps in code | [Workflows](/docs/concepts/chains) |
| coordinate several agents | [Multi-agent systems](/docs/guides/advanced/multi_agent_systems) |

| test without a live model | [Testing](/docs/concepts/testing) |

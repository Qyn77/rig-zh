# Cookbook

Every example below lives in the [Rig v0.44.0 examples directory](https://github.com/0xPlaygrounds/rig/tree/v0.44.0/examples) and is a complete, runnable program that Rig’s CI compiles. Use this page to find a starting point, then read the source for the details. Each example’s `src/main.rs` opens with a comment saying what it shows and which keys it needs.

## Basics

The smallest useful programs for the core building blocks. Concepts: [Agents](/docs/concepts/agent), [Completions](/docs/concepts/completion), [Structured Output](/docs/concepts/extractors).

| Example | What it shows |
| --- | --- |
| [`agent`](https://github.com/0xPlaygrounds/rig/tree/v0.44.0/examples/agent) | The provider → model → agent → prompt flow end to end. |
| [`extractor`](https://github.com/0xPlaygrounds/rig/tree/v0.44.0/examples/extractor) | Typed extraction into a struct, with and without usage metadata. |
| [`sentiment_classifier`](https://github.com/0xPlaygrounds/rig/tree/v0.44.0/examples/sentiment_classifier) | The smallest typed extractor, used to classify a sentence into an enum. |
| [`multi_extract`](https://github.com/0xPlaygrounds/rig/tree/v0.44.0/examples/multi_extract) | Several extractions of one text in parallel with `futures::try_join!`. |
| [`agent_with_context`](https://github.com/0xPlaygrounds/rig/tree/v0.44.0/examples/agent_with_context) | Static context documents attached to an agent (Cohere). |
| [`agent_with_loaders`](https://github.com/0xPlaygrounds/rig/tree/v0.44.0/examples/agent_with_loaders) | Loading files from disk into an agent’s context with `FileLoader`. |
| [`frozen_api`](https://github.com/0xPlaygrounds/rig/tree/v0.44.0/examples/frozen_api) | Eight short programs (`cargo run -p frozen_api --example p1_one_prompt`, …): one prompt, streaming, an erased model, tools, local and HTTP operations, an OpenAI-compatible vendor, a custom transport. |

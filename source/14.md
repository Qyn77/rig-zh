# Embeddings

An embedding is a vector representation of data, usually text, where semantically similar items map to nearby points. Rig turns your data into these vectors so you can power semantic search, similarity comparison, and [Retrieval-Augmented Generation](/docs/concepts/rag).

In Rig, an `Embedding` holds the original text (`document`) alongside its vector (`vec: Vec<f64>`).

@@ANCHOR:best-practices@@

## Best practices

- **Prepare documents.** Clean text before embedding, and split large documents into focused chunks.
- **Match models.** Embed queries with the same model as the stored documents. Vectors from different models are not comparable.
- **Batch.** Prefer `.documents(...)` for many items so Rig can batch requests.
